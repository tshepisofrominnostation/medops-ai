# In Process — team drafts and pre-code work

This folder is where each member shows their work BEFORE it becomes code.

## The rules
- Each member owns one subfolder (named for you). Work in your own folder only.
- Put drafts here: design notes, architecture sketches, response template ideas,
  test scenarios, research, screenshots. Thinking, not finished code.
- Code does NOT live here. Code goes on a feature branch -> pull request -> review.
- A draft the team likes becomes a story on the sprint board, gets built on a
  branch, and graduates out of this folder. The PR history replaces the draft.

## How a draft becomes real work
1. You draft in in_process/<your-name>/<topic>.md
2. Team discusses it at stand-up or in the comments
3. If agreed: it becomes an issue on the board
4. You build it on feature/<story> branch, open a PR, reviewers approve
5. Merged draft either moves to docs/ or is deleted, superseded by the real work

Why this exists: every member's contribution is visible and on record before
any code exists. Nothing here is "final" — it is the team's shared workshop.
